# gen-tree

Семейное исследование: Миникаевы (Магнитогорск) по линии отца и Абзалутдиновы / Гилемовы по линии
матери; отдельная ветка — супруга, Милана Константиновна (в девичестве Рябова).

## Что открыть

- `index.html` — итоговый отчёт для чтения: древо, линии отца и матери, Фомкино, архивные находки,
  связи, хронология, источники.
- `gen-tree.ged` — древо в GEDCOM 5.5.1 (18 персон, 13 семей) для импорта в любую программу.
- `final-report.md` — рабочий текст исследования с матрицей утверждений и статусами.
- `research-state.md` — что уже проверено, что осталось и какие маршруты заблокированы.
- `case-intake.yaml` — рамки дела, согласия и ограничения.
- Реестры: `person-register.csv`, `claims-register.csv`, `relationship-register.csv`,
  `artifact-register.csv`, `search-log.csv`.
- `input/` — дословные записи сообщений субъекта; `sources/` — сохранённые архивные страницы и
  выписки; `photos/` — описание поиска фотографий.
